# COM30 Taller 06 — Reserva de espacios

Aplicación de una sola pantalla para registrar solicitudes de reserva de espacios universitarios. Cada solicitud incluye responsable, espacio, fecha, horario, asistentes y una lista dinámica de recursos. Los registros se guardan en memoria mediante un servicio Angular con signals y su estado se puede cambiar desde el listado.

## Requisitos

- Node.js compatible con la versión de Angular del proyecto
- npm, incluido con Node.js

## Ejecutar

```bash
npm install
npm start
```

La aplicación queda disponible en `http://localhost:4200`.

## Compilar

```bash
npm run build
```
